Before You Submit

Important information for publishing consideration

  • Provide your correct author name and contact information.
  • Enter the complete title of your manuscript.
  • Select the most appropriate type of book.
  • Upload the complete manuscript for consideration.
  • Accepted file formats: PDF, DOC and DOCX.
  • Maximum file size: 20MB.
  • Make sure the uploaded file is readable and complete.
  • Submission does not guarantee publication; every application is subject to publishing-house review.
Incomplete manuscript, failure to meet submission requirements, poor or unsuitable file quality, incorrect or incomplete application information, manuscript not suitable for the publishing house, duplicate or previously submitted manuscript, or other publishing requirements.
